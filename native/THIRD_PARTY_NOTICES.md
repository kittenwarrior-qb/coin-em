# Scaffold provenance

Android/iOS project templates and Gradle wrapper were generated by official `@capacitor/cli` 8.5.3 with Capacitor Android/iOS 8.5.3. Runtime App 8.1.2 and Network 8.0.1 plugins are installed from the pinned lockfiles. Refer to the respective package LICENSE files and [Capacitor source](https://github.com/ionic-team/capacitor).

Generated launcher/splash imagery is still template artwork and must be replaced by approved EmCoin brand assets before a distributable release. This record is provenance, not a blanket license/privacy/store approval for the app, fonts or content.
