# Admin CRM refinement

Owner request: fixed-height desktop workspace, adjacent sidebar, clean searchable tables and reasonable theme-specific colors/icons. Reference screenshots guide layout only; no fabricated visitor/charts/CRM customer data.

## UI implementation

- Desktop:100dvh shell; sidebar232px touches the right content pane. Removed the centered1200px child that caused huge gaps on wide/zoomed-out viewports. Header stays fixed; the workspace has the only main vertical scroller. Mobile remains a stacked document, with bounded horizontal table scrolling.
- Neutral card surfaces, restrained borders and type hierarchy. Orbit uses violet actions; Workshop uses blue actions and warm neutral surfaces. Red is destructive, amber means unchecked, green means reviewed. Original gameplay BrandIcon family reused. Admin buttons are compact native controls rather than oversized raster game pills; portal dialogs have explicit color fallbacks.
- Catalog table: code,name,category,order,review status,edit action. Accent-insensitive Vietnamese search,category/status filters,10-row pagination and explicit empty state. Version preparation/activation stays in a disclosure; original server revision/idempotency and review safeguards unchanged.
- Room table: searchable metadata only; existing explicit revision-checked close confirmation preserved.
- Card form: two editable columns with paired previews in a separate right rail; sticky save/return actions. No card art or rules edits.
- Theme selector in topbar changes only local UI preference, including while editing; draft and mounted state retained. Owner-approved themes only.
